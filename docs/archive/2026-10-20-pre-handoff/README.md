# ytrader

以产业链为核心的中文投资研究 Web：理解产品、环节和服务的联系，找到参与公司，再按需深入个股分析。React / TypeScript、FastAPI、SQLite。核心代码采用 MIT；第三方数据权利另见 [THIRD_PARTY.md](THIRD_PARTY.md)。

产业解释采用统一流程：产业输入 → 节点与真实关系 → 主干/分支/配套分组 → 结构校验 → 同一页面呈现 → 环节与公司详情。三个公共参考与AI内容共用结构契约；旧AI版本只读兼容。当前为可体验草稿，用户尚未认可本轮体验，不能把结构完整视为行业知识已核实。产品逻辑见 [产业链核心逻辑](docs/CHAIN-CORE-LOGIC.md)，本轮实现见 [通用产业解释流程](docs/INDUSTRY-PIPELINE-BRIEF.md)，三个实例与开源源码研究见 [产业链结构研究](docs/INDUSTRY-STRUCTURE-STUDY.md)。

## 新闻雷达当前体验

[打开新闻首页](http://127.0.0.1:58710/events)。独立本地预览已接三路真实公开源，支持来源管理、组合筛选、原文阅读与修订记录。产业入口保留此前桌面稿。数据质量相关45项检查通过；页面仍为可体验稿，长期源稳定性和全面UI回归未完成。研究与边界见[开源采用记录](docs/NEWS-RESEARCH.md)、[新闻验证记录](docs/NEWS-VALIDATION.md)。

## 本地启动

需要 Python 3.12+、[uv](https://docs.astral.sh/uv/)、Node.js 22+。

```bash
uv sync --extra test
npm ci --prefix frontend
npm run build --prefix frontend
uv run ytrader serve --data-dir .local/data-v1
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。开发界面可另开终端执行 `npm run dev --prefix frontend`，访问 5173；API 仍运行在 8000。

1. 在“设置 → 数据更新”同步新闻和证券。首次数据库为空，没有演示新闻或模拟分析。
2. 在“资讯”阅读新闻正文、来源与时间；普通新闻无需分析或产业关联也可独立阅读。
3. 在“产业”查看 AI算力、原油、创新药的主干、配套与分支。点环节看作用、相邻关系与公司，切换公司视角定位参与位置；公共参考与已保存 AI 补充在同一个工作区切换。公共参考无需模型或导入，新闻的旧主题路径仍保留。
4. 公司页提供基本资料、业务范围、产业位置、近期资讯和辅助行情；需要时再展开“独立公司研究”。事件研究与公司研究分别保存。
5. 在设置中填写自己的 OpenAI 兼容模型地址、模型名称和密钥，保存后测试连接。产业页可追问缺失环节，或按产业名称生成初稿。结果在后台生成并保存，保留模型、日期和 AI 标识。未配置模型仍可阅读公共参考。
6. 数据与 AI 可分别切换为 ycore，需自行提供支持对应契约的服务。此仓库没有开通远程 ycore 或付费数据源。

## 研究能力

- 新闻来源目录、去重、保守事件聚合、更新与纠错记录、重要性和关注相关性排序。
- 沪深北证券主表、搜索、关注和行情状态；公开源快照与全市场独立对账分开报告。
- 统一产业结构：产品、活动、服务与应用；区分投入产出、组成、支撑、用途和流程先后。三个公共参考合计25节点、23关系、7公司、13条参与角色映射。
- AI 可用一般知识补充缺失结构与解释，但不覆盖公共参考，也不能伪造来源或证券代码。主表精确匹配后才生成公司入口；无匹配保留名称。
- 历史行业分类、披露供应和推断关系继续可读，支持导入注明许可、来源及时间的产业包。
- 公开公司档案按需获取并缓存 24 小时；失败保留旧资料与已有业务关系。工商经营范围不等于收入构成。
- 事件与独立公司研究均支持事实、关联环节、公司、条件、反证、待验证事项六类分析；引用校验与证据版本失效。
- 持久后台任务、来源故障隔离、定时更新；本地数据/托管 AI 等四种组合的适配契约。

模型与真实 ycore 的线上可用性依赖用户配置。Jev 保留候选能力声明，未实测前不启用。未经许可核实的 ChainKnowledgeGraph 数据不随版本分发。分类关系不是实际供货关系。

产业页“旧主题、行业目录与数据包”入口可一键安装锂电、稀土、半导体与算力、半导体设备、光伏、工业自动化、医疗器械七个主题包，也支持导入自己的 JSON。包保留官网/年报证据，新数据库不会自动载入；这些小型包不代表全市场供应链。格式与更新规则见 [DATA-PACKS.md](docs/DATA-PACKS.md)。
