# 产业解释能力实施基线

2026-10-18。用户已明确“就按照这个思路做”，允许AI补充解释和数据未覆盖处。目标是产业链讲明白，有数据、有结构、有解释；本轮进入实际实现和体验验收。既有“先别做UI”针对此前缺内容的展示迭代，本轮只做承载已明确逻辑的必要阅读交互，不进行独立视觉重设计。无提交、推送、远端部署、采购授权。

## 用户结果

1. 进入产业后能直接阅读AI算力、原油、创新药的真实公共资料结构，不需要先安装旧稀疏主题包或调用模型。
2. 每条产业先讲清服务什么需求、主路径如何连接、支撑与分支在哪里。节点和每条关系可以查看一句话解释与来源，公司显示参与角色并可进入现有公司档案。来源与研究边界按需展开。
3. 用户可以针对已有产业发起AI补充，解释不懂的部分、补充缺少的环节。AI不局限于复述输入资料：允许用一般知识补充，但必须标为AI补充；未核对的关系与公司参与不冒充已核实事实。
4. 用户输入尚无公共资料结构的产业（如低空经济），可以生成可保存、可返回查看的AI产业初稿，仍有结构和解释。不得静默伪造公开来源。初稿明确是AI知识整理，非已核实当前全覆盖。
5. 离开页面不丢后台任务，完成后能返回结果；刷新和重启后保留。AI失败时已有产业仍可读。公司能返回出发产业；公司页可找到已收录的产业位置。

## 数据基线

backend/data/industries/*.json由Codex维护，三份公共资料参考结构从docs/examples/industry-structure提升；不是演示公司和新闻，不注入证券数据库。每个节点、关系、公司参与有sources。关系类型input_to/produces/component_of/supports/used_for/precedes；支持按需增加明确的替代/循环类型但不要膨胀本体。数据包含简短解释、关键区别、范围缺口。机构流程说明只支持其具体范围；FDA仅流程例子，不能推广为中国注册细则。

公司identity来自本机已同步沪深北证券主表核对：浪潮信息SZ:000977，中国海油SH:600938，上海石化SH:600688，恒瑞医药SH:600276，泰格医药SZ:300347，凯莱英SZ:002821。NVIDIA只作产业参与者，不伪造A股链接。AI新建议公司不接受模型随意填写证券代码，必须由服务端对主表做明确身份匹配；不确定时显示名称与待核查，仍可全文查公司。

统一五部分：industry、nodes、relations、companies/participations、sources。新增讲解层可以采用overview、主线解释与关键区别，以及gaps。财务、估值、收入权重和临床成功率不是必填，也不做公司分析的重复功能。

## 实现约束和建议

- 新模型应独立于旧classification/upstream包，不强行挤进旧图契约。保持旧主题/目录/导入入口兼容，主产业入口优先提供新产业内容。可使用/chain?industry_id=...与/chain?legacy=1，或等价清晰路由；历史新闻/公司topic_id仍能返回。
- 推荐新增/industries列表/详情/生成与补充API，使用既有envelope。后台复用Jobs，设置明确任务类型和target_url；按产业及请求去重，不把所有产业任务去重为同一个。模型地址、模型名、ai_mode在运行时核对，不能切换账户后发送到旧目的地。
- 公共参考内容包直接随软件提供只读；AI结果在用户数据库独立保存，不改包、不覆盖来源事实。记录实际模型、创建时间、输入版本。重复补充保留上一份有效结果直到新结果成功；公共基础变更后旧补充标记需更新，不假装当前。
- AI输出采用可验证结构：稳定/局部ID、节点类型、关系类型、引用合法端点、公司参与映射、解释。一般知识允许无来源但一律AI标记；不接受AI新造URL当来源。已有sources引用须为给定ID。不要自动把模型自称“公开事实/已验证”升级信任。
- 输入名称和问题有长度/空白限制，JSON结果与图规模有边界；结构错误、截断和未知引用不得损坏旧数据。真实模型可能需要足够输出token；保留可读错误，不能回显凭据或响应敏感内容。
- 模型使用现有设置及Network/model_headers。local数据与AI模式仍独立；若ycore尚不支持此能力，明确能力不可用，绝不静默调用本地或伪装远端已验证。尽量复用远端capability接口机制。
- UI沿用已有字体/颜色/间距。阅读主线优先，可读关系图/流程与关系说明相互对应；不同语义必须显式标注，支持分支及横向配套，不强制三列。窄屏不靠缩小整张图，节点明细/列表须可读。关键内容不得全部藏在折叠项；证据可以按需展开。
- 不显示JSON字段名、内部任务ID等实现细节；不要堆大量“待确认”警告替代内容。AI标识与来源状态简短清楚。生成动作明确，不能每次访问自动调用模型。
- 保留用户已有模型设置、密钥、数据库和新闻/个股研究。不得读取/复制/输出凭据。工作者不运行代码、不联网、不递归委派；Codex执行测试、真实模型和浏览器验收。

## 完成检查

公共内容：三个产业主线/分支/支撑和公司角色可解释；无需模型可用。AI路径：已有产业补充问题、未覆盖产业初稿都真实运行并持久化，语义可读，无编造来源与错误公司跳转。三种不同关系结构在页面可分辨；从产业进入公司后正确返回。自动测试覆盖引用/端点、AI来源边界、重复任务、失败保留与版本；浏览器验证实际阅读路径及窄屏。测试数量不替代产品内容判断。
