# 产业数据包

开放产业目录通过适配器读取七个有来源的主题包，作为可查阅来源记录。已有ChainPackage导入接口保留；新数据库不自动注入关系事实，导入不触发AI调用。包保存在 `backend/data/packs/`，可独立导入的副本在 `examples/recovery-packs/`。

共 40 节点、43 关系。公司与已有证券主表按 ID 合并，所以不能把包节点数加到证券总数。具体原始 URL、原创事实摘要、日期、引用 ID 均在包 JSON 内，界面可打开证据核查。

包的原创编排与短摘要按本仓库 MIT 发布；原网页保留各自版权，不复制完整网页。关系以公司业务分类、产品及产业环节为主，没有两家公司之间已核实的供应合同边。这些包不是全 A 股产业库。

一般 `as_of` 为 2026-10-18 核读日期。页面未给发布日期时 `published_at=null`；不能将核读日期当作公司公告时间。光伏历史上下游依据 2022 年报，边的 `as_of=2022-12-31`，年报摘要发布日期 2023-04-28，不能当作最新产能或订单状态。

用户可通过 `POST /api/v1/chain/import` 导入自己的 ChainPackage。新增包须保留可追溯来源、明确时间与许可声明；无来源、许可不明或断裂引用不得导入。许可字段只表达包作者的授权，不能替未经授权的第三方数据库重新许可。未披露日期可保留 null 并明确提示。

上下游边描述产业环节位置；分类边只表示业务关联，不表示采购、订单或确定受益。研究传导时仍需核实配方、库存、长协、需求与价格转嫁能力。
