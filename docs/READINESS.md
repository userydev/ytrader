## 3. 数据与来源决策

### 发现与正文分开放行

1. **国内综合发现候选：中新网官方RSS。** 官方[订阅目录](https://www.chinanews.com.cn/rss/)提供即时、时政、财经、国际等入口；本次仅验证[即时流](https://www.chinanews.com.cn/rss/scroll-news.xml)。先用于个人阅读线索和回原文入口。该站同时声明限制未经授权转载、摘编和复制，不把全文落库、传给模型改写或公开分发默认放行。具体保存/处理范围由来源登记控制。
2. **原始补证：相关机构和公司原始披露。** 本次验证了[美联储RSS](https://www.federalreserve.gov/feeds/feeds.htm)。其[使用说明](https://www.federalreserve.gov/disclaimer.htm)允许使用未另行标注权利的官方信息，并要求来源标注；不扩大到第三方材料、标识或全站内容。国内政策与公司披露按具体事件补证，不以媒体转载代替原始发布。
3. **金融及公司补充：现有iFinD MCP。** [官方指南](https://mcp.51ifind.com/#/docs/guide-prepare)明确支持AI应用接入；已有新闻、公告、主营业务和产业关系的有限实查。使用现有试用进行有限接入验证，不先购买。没有原文链接、空正文、时间缺失、摘要数字不一致均不得直接支持强结论。长期自动保存与对外分发未核实，不能随技术接入一并批准。
4. **广泛外部发现候选：GDELT。** [官方说明](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/)提供多语言检索和结构化输出；[数据条款](https://www.gdeltproject.org/about.html)允许使用其发布的数据集。此次一次请求返回429，已停止；保留候选，不将它记为已可用，也不由一次限流判定永久不可用。GDELT的数据许可不转授新闻原站全文权利。

统计局RSS两次有界读取均为HTTP 200，但读取上限分别为200KB、2MB，未得到完整可解析文档；不判定端点失效，也不纳入已验证组合。CNINFO网站内部检索接口未发现足够的开放API依据，不承诺直接批量抓取。

**开工后的首个放行条件**：至少形成可持续的综合发现与合法原始补证路径，冻结少量真实资料和预期，覆盖重要非财经变化、政策/公司披露及证据不足停止。国内综合、外部发现、金融补充分别记录覆盖缺口；不以单源查询成功宣布完整覆盖。资料使用条件未确认的源保持禁用对应处理能力。

### 基本面最低字段

首版至少需要：证券代码与公司名称、最新可得报告期/发布日期、币种和单位、营业收入、归母净利润、经营现金流、总资产/总负债/净资产、主营业务及构成，以及可比期间和出处。比较增长或现金流质量时必须有同口径可比数据；季度累计值不能当单季度值。

iFinD已验证主营业务返回，不代表上述财务字段整套已通过。首包选一家公司逐字段核对原始定期报告；缺项仅展示已知事实和缺项，不能生成完整经营结论。全市场批量接口不是首包前提，也不宣称不存在其他可行接口。

## 4. 模型与网关决策

选择**现有Gemini API/BYOK通道**，由ycore提供统一模型执行，ytrader持有提示词和业务判断。本轮不增加供应商、不启用Workers AI、不切换统一计费、不新增充值。真实生成探针直连Google，完整网关路径尚待工程验证。

现有Gateway的现场设置：认证开启、60请求/分钟；提示词/响应日志关闭；成本限制关闭；自动重试1次；`Require Provider Credentials`关闭，页面说明无适用凭据时可能走统一计费；Workers AI为标准计费。

架构决定如下，无需用户逐项选技术：

- 为本项目配置隔离的调用策略和额度，不直接改动可能被其他产品共用的网关。配置前确认消费者和凭据范围。
- 固定Google BYOK及模型白名单；无匹配凭据就失败，禁止意外走统一计费或另一个供应商。
- 禁止网关和ycore叠加重试；供应商结果未知仍按既有架构保留unknown，不再次派发。实现时核实实际接口支持的配置方式。
- 应用侧预算预留为必需，Gateway成本限制仅作额外防线；不能用60/min限速代替金额上限。继续关闭提示词/响应日志，只记必要调用元数据。
- 第一次真实联调先验证鉴权、明确计费归属、单次调用数和用量，再启用后台批次。临时直连探针不成为产品绕开网关的正式路径。

建议用户批准的初始运行上限为**1美元/日、10美元/月，按先到上限停止**，包含调试及后台分析；不含另需批准的数据采购，也不自动充值。金额是建议的封顶预算，不是账单预测。最终模型在首包样本上选择，不能凭本轮OK探针宣称语义质量合格。
