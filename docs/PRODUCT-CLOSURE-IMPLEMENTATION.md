# 产品闭环实施回执

本次为实现候选；未执行命令、测试、浏览器或网络请求。集成与代表性体验由 Codex 执行，以下不声明运行验证通过或性能实测值。

## 已接通

- **公司 → 产业位置**：`GET /api/v1/securities/positions?symbols=SZ:300750,...`（最多24项）统一聚合原五图、Atlas、证据包、已保存基础研究/有效回答，以及可选 CKG 精确代码反查。证券卡片按当前页一次查询；公司四 Tab 使用同一能力，不再下载全目录图。原单公司 `/securities/{symbol}/industries` 增量返回相同 `roles`，保留旧 `items`。
- **CKG 反查**：公司行业、主营产品表按证券代码建进程内只读缓存索引，支持 `300750.SZ` 等后缀格式。不按公司名称猜代码。分类打开分类页（不伪造上下游节点）；主营打开对应产品中心节点，并携带公司所在记录分页。保留文件/行号、快照日期与 commit。外部目录仍仅由可选 `YTRADER_CHAIN_REFERENCE_DIR` 提供，不复制数据。
- **实际产业解释**：适配器完整保留 `explanation`，原产业页面以文本 DOM 展示概述、步骤/节点、区别、待核实问题和缺口；引用可打开原文，步骤可定位节点，分组/关系保持。兼容的原三份公开参考解释也增量进入原图；原五图不改写。没有解释的来源可独立生成 AI 研究。
- **保存与追问**：原研究入口复用 `/industries/{id}/supplement` 与后台任务。输入问题、进度、失败、已保存回答均可读；完成后打开本次回答，而不是只返回旧基础图。`GET /panorama/{id}?result=base|result-...` 可查看基础或指定有效回答，未指定时 AI 产业默认最新有效回答；原五图默认仍为来源图。原页可切换已保存问题/基础解释，AI 结果不覆盖来源。
- **复用身份**：`GET /industry-research/resolve?name=...&source_id=...` 查询已有研究；开放生成接口命中同名/同源结果直接返回 `status=cached`、`industry_id`、`target_url`，不重复调用模型。目录、关联目录与公司反向索引按保存序号失效；旧 `open-*` 研究入口可打开已保存研究。
- **新闻闭环**：继续保留 news/progress/return。当前所选 `result` 从原页传到 panorama 与影响 GET/POST；影响缓存仍绑定新闻稿件版本及当前图版本，不迁移其他新闻的研究结果。公司位置链接也携带对应回答/节点/分页。
- **冷启动工作量**：推荐候选先执行原 evaluate/diversify，仅对最终选中的新闻补开放产业 projection；详情按读取增强。保留原推荐排序、证据、多样性与全部行业覆盖。宽关联表达式另作有界编译缓存，保持原匹配语义，避免超出 Python 全局正则缓存后重复编译。未增加模型 GET 或全 feed AI。
- **未映射公司**：财务/资料/新闻保持独立读取；提供来源业务标签、实际产品收入标签或手工按资料输入产品的研究入口，不把粗分类包装成已证实产业链。

## 接口与边界

详见 `docs/contracts/company-industry-positions.md`。AI、来源位置、行业分类、主营记录分别标识；CKG 仍是 2021-10-26 历史资料，不是当前收入占比、公司间供货或完整覆盖。Atlas 保留 MIT 来源归属。

## 实际剩余限制

- 证券主表快照覆盖不等于第三方完整对账；有些公司仍无来源位置，AI 角色不是独立核实结果。
- CKG 可选目录未配置时只显示包内资料/已保存研究；索引随服务进程缓存，外部快照若变更需重启，不实现文件监视。首次读公司位置仍需一次建索引；具体产品图首次打开仍按现有只读适配器读取，邻居/公司有界分页。
- 补充以既有基础版本为基线，独立保存，不是无限聊天历史；过期回答不投影为当前节点。未收录或过期的指定结果返回错误，不偷偷换图。
- 远端 ycore 未声明对应位置/结果选择能力时明确不可用，不悄悄切换本地或用基础图冒充所选回答。
- 未增加来源、服务、框架、设置或全量复制。未修改历史 source 快照、数据/模型配置、运行脚本或凭据。性能收益与宁德时代/已有机器人解释及追问体验待 Codex 必要启动检查。
