# 新闻选题算法

目标：把新闻变成产业研究入口。现用入口为 `http://127.0.0.1:58730/events`；算法版本以 `backend/algorithms/` 注册值和响应字段为准。

## 来源与算法各自负责什么

来源决定候选覆盖范围和证据上限。算法决定哪些信息值得先看、哪些只是重复、与哪些产业变量有关。更多来源不会自动带来更好的首页。

| 候选入口 | 要保留的证据 | 不能作出的推断 |
| --- | --- | --- |
| 世界局势与宏观/产业报道 | 实质动作、涉及主体、源发布时间、原文摘要 | 出现“战争”就必然重大；有股价变化就找到原因 |
| 主流媒体头版 | 首页版本、观察时间、版位/所在区域；只有首页精选流则明确记精选 | RSS第一条等于主头条；首页位置永远有效 |
| 权威独家和二手转述 | 独家声明、被引媒体、实际拿到的稿件/摘要、可用原始链接 | 被多次转载等于多方独立证实；先抓到等于首发 |
| 官方公告/数据 | 原始发布主体、文号/日期、关键新事实 | 官方来源意味着内容对所有产业都重要 |

来源目录包含BBC、Guardian、Al Jazeera、NYT、FT及中国新闻网、华尔街见闻、IT之家等公共入口。来源可能失败，健康状态留在后台接口；不把“HTTP 200但HTML”当RSS成功。不通过付费墙、不把摘要称全文。

## 筛选流程

1. **质量门。** 排除广告、促销、下载页、荐股榜单和明显无关娱乐；保留可追溯来源与时间。未知发布时间不伪造，旧稿不因再次抓取变新。
2. **事实与判断分开。** 提取谁做了什么、改变什么变量、信息是新增/更正/背景/观点。规则识别的类型、关联和条件是判断，原文标题、URL、日期是证据。
3. **三路召回。** 重大事件/投资催化、媒体首页、权威独家各自进入候选。单源独家不会因没有多家报道而天然出局；空缺不填假条目。
4. **排序。** 优先具体变化、影响路径、实质新增、独立出处和有效媒体版位；时效衰减。纯价格回顾、没有新事实的评论、重复转述降低优先级。
5. **重排。** 同一持续事件限制占位，防止一个高频源或一个产业刷屏。来自同一通讯社的转载不能制造独立来源数。
6. **解释与留证。** 入选理由、原始出处、产业传导与不确定条件可查。算法版本、分项和排除理由用于后续重放，不把启发式分数展示为市场影响概率。

当前实现先按重要性层级排序，再在同层内结合具体变化、时效、首页观察、精选、独家和出处信号重排。单个持续议题最多占四条；同媒体重复占位有有限惩罚。BBC 首页采集保存观察时间和位置；Guardian、NYT、FT 精选流只标“首页精选”，不推断版位。首页观察或独家可以独立召回，不能因为没有命中经济关键词就全部排除。数值出现本身不构成重大变化，例行债券发行、体育和娱乐稿受质量门约束。

真实采集还暴露了 RSS 图片说明覆盖新闻摘要的问题。适配器现按 XML 命名空间区分正文与媒体描述；旧版本保留，但旧图片说明不再优先展示。排序和时间线使用当前有效稿，历史修订仍可回查。

## 三层信息组织

**稿件版本 → 新闻进展 → 持续议题。**

同一稿件改了数字，要保存版本；多个媒体报道同一进展，要保留各稿；同一长期议题发生新动作，要形成新的时间线节点。共享“AI”或国家名不足以把两条新闻合成一件事。系统只展示实际已收录的历史，不用生成文字伪造之前发生过的新闻。

## 多产业关联

宽关联提供产业入口，可保留空节点；进入所选产业后，条件影响再说明新闻证据、变化变量、机制、条件与真实节点。两者均可一对多，不把主题相关当成已证实传导。

- 航运受阻：原油可用供给与运费有条件变化；黄金关联取决于避险需求是否上升；没有芯片、资本开支或能源约束证据时，不强行关联AI。
- AI资本开支或融资变化：可能影响服务器、芯片、互联与电力设备订单；承诺投资不等于已兑现收入。
- 利率/美元变化：可能改变黄金机会成本与科技估值条件；不能直接翻译成所有黄金股或AI股上涨。

关联是进入产业图的入口。产业图展示环节分工和对应变量；公司受益还取决于业务暴露、产量、成本和合同，不从新闻标题直接给买卖结论。

## 后续校准标准

方向获用户认可后，再建立带时间切面的标注集。先看重大遗漏、噪声占比、重复占位、独家漏失、错误产业关联、旧闻冒新；不要以点击量或短期涨跌单独衡量新闻质量。回放只能使用当时已知信息，不能拿后来的结果倒推“当时必然重要”。

当前规则版本先解决可解释、可复查的选择过程。跨语种语义合并、复杂否定/讽刺、无显式出处的转载识别和长历史连续性仍需更强语义层及数据校准；不宣称已经达到完整自动新闻编辑能力。
