# 新闻—事件传导—产业—公司 · 候选回执

本轮为可体验交互草稿，未获用户验收；worker 未运行命令、构建、测试、浏览器或实时网络请求。集成与运行检查交 Codex。

## 设计判断
- 新闻首屏增加当前 feed 中最多三条传导线索，不改变推荐排序。列表收紧为标题、两行摘要、来源时间及变量预览；无关联不强挂。
- 选中标题即展示传导，包含约 704px 的窄窗口：传导在正文/进展/媒体切换之前，不再藏在产业 Tab 中。宽屏给阅读区更充足宽度。
- 新闻与原产业图复用同一 `core-transmission`：触发、变量/机制、可点击的并列环节和公司卡片。主视图保留每条路径一个条件提示；方法、结构边、映射缺口与完整条件在来源详情。
- 环节依据原图 ID 校验，业务边只取真实 relations，不按 node_ids 顺序编造箭头；公司只取该环节真实 participations 并展示角色。静态业务关系不是本次新闻已影响财务或股价的证据。
- 独立产业入口读取真实 `/news/editorial` 的当前推荐，筛选本产业关联；点选携带 event/progress，在原图高亮。静态 observatory 样本不再充当当前新闻。仅新增紧凑横向事件卡片，不缩小原图，不改业务视图、图层与搜索的定义。
- 新闻 → 环节/公司单层直达。原图内点击复用原交互；公司沿用原四 Tab。URL 保留 news、progress、node 与安全 return；原图往返另做可选会话快照，保存图层/视图/选择与滚动。源新闻返回带所选进展。
- 个股目录为响应式卡片，每页24家：真实名称/代码/交易所，已有行业、精确 symbol 匹配的图参与角色/业务摘要。最多读取五份现有产业图，不逐卡请求财务；无图公司仍可独立进入原公司详情。保留筛选、offset、return、空态、错误与来源更新。

## 数据与机制修正
- `industry_transmission` 恢复候选升至 1.2.1，旧 v1 字段及 editorial rule_version 保留。
- IEA“石油储备的释放时机由各成员国自行决定”映射为**释放安排 → 可动用库存/投放节奏 → 条件性的原料/燃料可得性**，不写成已释放、已新增市场供给或开采产能。柴油单列燃料产品；原油/混合释放与实际投放品种须核实。不以此标题命中 extraction。
- 生产调整须有明确减增产等词组；通用“供应”不再充当生产证据。储备释放需在同句具有油品证据，不能把其他物资储备挂原油。
- 现有窄门保持：战争不自动挂黄金、泛 AI 不猜采购、外国电厂受袭不挂中国电网订单。五行业内无足够证据者仍空缺，未追求覆盖率。
