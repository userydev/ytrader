# ytrader 产品定义（V0）

> 2026-10-15 修订。全新开发的产品需求基线；不恢复旧代码或旧计划。**本文件以本次用户纠正为准，明确替代此前「波段交易指导 / 交易计划 / 持仓管理」方向。**

## 1. 定位

**ytrader 是我个人使用的 A 股信息与研究工作台。** 它负责把新闻事件、相关产业链、影响传导、产业链上的行业板块与上市公司，以及具体个股的多个分析策略，连成一条容易浏览、能追溯依据的信息路径。

**核心流程：新闻 → 关联产业链 → 事件影响的传导过程 → 板块 / 个股概览 → 个股多策略分析。**

系统提供信息、分析视角、事实依据和不确定性；**是否交易、何时买卖、持有多久，完全由用户判断。** 用户提及主要做波段，仅用于理解使用背景，**不构成产品功能或数据时效的固定约束**，不为某一持有周期设计交易指令。

首期用户仅项目负责人；A 股优先，以网页为载体。ytrader 是唯一产品需求源。Y-Core 在独立仓库开发，但仅负责 ytrader 实际需要的技术供给。

## 2. 必须呈现的信息路径

### A. 新闻：发生了什么

- 首页首先是可阅读的新闻与事件，支持按时间和产业主题浏览，显示标题、精简事实、发生/发布时间、来源和原文入口。
- 区分**新闻报道、公司公告、政策文件、统计数据**；来源只提供标题时不得编造正文，转载不冒充独立证据。
- 一条新闻可以关联多个产业链，也可以暂时没有可靠关联；点击进入其事件详情及相关产业路径，不自动生成交易建议。

### B. 产业链：影响怎样传导

- 展示产业链的上下游结构、主要产品/环节及各环节如何连接；无需有新闻也可以浏览基础链条。
- 新闻叠加到相关环节后，解释**直接变化 → 上下游可能怎样受到影响 → 相关板块和公司**。需要指出机制、条件、支持依据及不确定性。
- **产业环节、行业板块、上市公司是不同层次**：一个环节可对应多个板块/公司；一家公司可跨多个环节。板块关联来自行业分类或业务资料，不等于事件已对全部板块个股造成影响。
- 让用户可以从新闻一路展开，也可直接进入产业链，点击板块和公司继续查看。

### C. 板块与个股：哪些主体相关、大概是什么情况

- 在链上对应环节呈现相关行业板块、代表性 A 股公司、主营业务及产业链位置，优先说明**为什么相关**。
- 板块展示基础状况、相关事件与必要的公开指标；个股展示主营业务、经营与财务概要、近期相关信息，以及在数据许可且可用时的基本行情/估值。重要数据标注期间、口径、更新时点。
- 区分「原文直接涉及」「有业务关联」「进一步影响待验证」，不把板块或上下游关系直接写成个股利好/利空结论。

### D. 个股多策略分析：从不同角度看同一家公司

- 个股页提供**多个可独立查看、可对比的分析策略**，而不是一份冗长的单一 AI 报告。
- 首批策略候选包括**经营财务、产业/事件影响、估值与市场表现**等视角；最终策略清单另行调研和筛选，不把候选当成已经采用。
- 每种策略要说清：**它看什么、采用什么方法、关键证据和指标、主要判断及反证、缺失信息和限制**。必要时用表格或图呈现，用户可以切换比较。
- 分析可以包含积极、消极或无法判断等观点；不要求策略意见一致，也不合成统一买卖评分，更不输出自动交易操作。

## 3. 页面与交互

首期控制在三类主页面：

| 页面 | 主要任务 | 跳转 |
| --- | --- | --- |
| **新闻首页** | 阅读事件，找到其相关产业链与影响摘要 | 新闻 → 产业链/环节 |
| **产业链页** | 看结构、事件传导、板块与公司分布 | 环节 → 板块/个股 |
| **个股页** | 看公司概况、相关事件、不同策略的分析结果 | 策略切换、证据回溯 |

新闻详情与板块概览可在主页面内展开，不为凑功能建立额外独立工作台。页面要支持从个股回到原事件和产业环节，避免断开阅读上下文。用户也可直接通过股票搜索进入个股分析。

## 4. 两仓职责

- **ytrader（产品）**：页面与交互、产业链/环节/板块/公司在产品中的组织、事件影响的展示语义、个股策略定义与分析结果的选择/呈现、用户阅读体验。
- **Y-Core（技术供给）**：按 ytrader 实际需要，提供可追溯的新闻/公告/原始材料、基本证券/财务/行情数据适配、受控 AI 执行与必要的缓存/状态/失败诊断。实现由真实消费需求决定，不独立扩成通用 Radar、研究或 Agent 平台。
- **协作**：两仓独立开发与测试；先由 ytrader 明确一条真实用户阅读路径和所需材料，再形成最小供给合同。两端联调后，必须由 ytrader 实际页面完成验收。

## 5. 首版范围与验收

**MVP：用一条真实新闻贯通 1 条产业链、若干环节、相关板块和至少 2 家有业务依据的 A 股公司；进入其中一只个股，可切换至少 2 种不同策略的分析结果，并能回看原始新闻与证据。**

验收只看四件事：
1. 我能在首页读懂新闻，查到出处与日期；
2. 我能看明白它对应哪条产业链、通过什么机制影响哪些环节；
3. 我能找到相关板块、公司，理解为何有关，哪些影响只是推测；
4. 我能在同一个股页看懂至少两套有明确逻辑和数据依据的分析策略。

首版**不做**：买卖建议、入场/止损/退出条件、交易计划、持仓与仓位管理、券商连接、自动交易、策略回测、统一交易评分、订阅收费、全市场行情终端、复杂多 Agent 平台。将来是否增加，必须由新的明确需求驱动。

实现方式、数据源、首个产业链和首批具体策略由后续样板与真实材料质量决定；不再向用户追问交易周期或持仓功能作为开工前提。
