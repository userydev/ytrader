# 产业链核心逻辑

2026-10-18，根据用户最新反馈收敛。本文件替换上一稿过细的经营、财务和指标要求。当前进入通用产业解释流程的可体验实现，产品价值尚未获用户认可。

## 产业链负责解释什么

让用户看懂：一项需求需要哪些产品和服务，这些部分如何连接，哪些公司参与其中。

产业链先提供稳定、可复用的公共知识骨架。新闻标记结构中发生的变化，公司连接到自己的产业位置。没有新闻和 AI 调用，骨架也应能独立解释产业。

产业链回答“做什么、为什么相连、谁参与”。公司收入构成、业务权重、盈利能力、估值、具体药物管线及财务预测归入个股分析。它们不构成产业链可用的前提。

## 统一结构

| 内容 | 必要字段 | 作用 |
| --- | --- | --- |
| 产业范围 | 名称、满足的需求、边界、简短解释 | 确定这次讲什么 |
| 节点 | ID、名称、类型、一句话作用 | 表示产品、活动、服务或应用 |
| 关系 | 起点、终点、类型、一句话依据、来源 | 解释两个节点为何相连 |
| 解释结构 | 机制、主旨、主干/配套分组、分工目的、主关系、阅读顺序 | 让读者直接看到产业怎样运作；不生成新的事实边 |
| 公司参与 | 公司身份、节点、参与角色、来源 | 把产业位置接到公司 |
| 来源 | 发布者、链接、定位、核查时间 | 支持核对与更新 |

节点按解释需要合并，不按公司财报分部拆解。公司可以参与多个节点，同一节点可以出现在多个产业视图。正式数据应共享稳定 ID；三个研究样例目前各自独立保存。

先用六种关系表达三个实例：投入、产出、组成、支撑、应用、流程先后。不是每条链都需要六种，也不把它们当作已经穷尽所有产业的最终本体。行业分类用于归类和检索，不参与上下游路径计算。

关系方向必须明确：部件→整机是“组成”；原油→炼制是“投入”；炼制→燃料是“产出”；临床前→临床是“流程先后”。配套设备和外包服务可以横跨多个环节。

每条主关系都能读成一句话。事实依据与编辑选取的边界、合并节点分开记录。公司参与不自动生成公司之间的供货关系，也不推导订单、利润或股价。

## 三个实例检验出的差异

| 实例 | 结构 | 需要保留的区别 |
| --- | --- | --- |
| AI 算力 | 部件组成系统，网络、存储、软件、供电和散热共同支撑运行 | GPU、光互连、散热不能排成依次加工的一条线 |
| 原油 | 原油经炼制形成多种产出，分别进入燃料和化工用途 | 多产出与分支不能压成单一产品；储运提供支撑 |
| 创新药 | 发现、临床前、临床、审评等流程，叠加研发及制造服务 | 流程先后不同于物料流；CRO、CDMO可以服务多个阶段 |

三个实例共同检验一套产品流程，不各写一页专用讲解。新产业的不同结构由数据表达，页面不判断产业名称。分组归纳与关系事实分开，新输出校验结构完整性，历史内容只读兼容。实施范围见 [通用产业解释流程](INDUSTRY-PIPELINE-BRIEF.md)。

实例、证据、开源源码发现与自动化判断见 [产业链结构研究](INDUSTRY-STRUCTURE-STUDY.md)。三例已按统一格式接入产业阅读页，仍不代表大多数产业已覆盖。

## 公共数据怎样成为结构

1. 用机构流程资料、技术参考架构、行业分类和公开产品目录确定节点与关系候选。分类只给词表，工艺资料才支持依赖关系。
2. 用公司官网产品和服务资料补“公司→节点→角色”。别名可以归一，集团与上市主体必须核对身份。
3. 抽取结果保留原文位置，再验证关系方向、类型、引用和名称；含糊记录留待核查。
4. 同一来源更新时比较变化，只复核受影响的节点、关系和参与角色。结构低频更新，新闻增量关联。

自动化的目标是重复采集、抽取、对齐与检查。首版结构的边界和语义仍需审阅。AI可以用一般知识生成初稿和补充缺失环节，但必须标明AI身份、边界、模型与日期；不能将其宣传为已核实的完整覆盖，也不要求先读完全部公司年报再建骨架。

价格、产量等公开行业数据以后可以挂到对应节点；按实际问题与可得性选取，不设置跨行业统一指标套餐。缺少动态指标不妨碍解释稳定结构。

## 内容完成标准

用户能读懂范围内的主路径和分支，解释主要关系，找到实际参与公司，并从公司返回相应产业位置。主关系有依据，未覆盖分支明确；分类、工艺、服务和商业关系不混淆。

经用户授权，三个公共参考产业、关系阅读、公司位置、AI补充与新产业初稿已落地，并完成真实模型和浏览器路径检查。公共来源自动抽取、持续更新和广泛覆盖仍待验证；AI输出质量按实际样本记录，不以任务成功或自动化测试替代语义核查。详见 [VALIDATION.md](VALIDATION.md)。
