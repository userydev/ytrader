# ytrader 开工决策报告

2026-10-15。基于角色设计及本轮账号、来源、模型、iOS和服务器现场核验。未开始应用开发；详细证据与限制见 [READINESS.md](READINESS.md)。

## 1. CEO判断

**建议有条件批准首个真实闭环工程包，暂不全面铺开。** 已有真实可调用的Gemini服务、Google BYOK网关、可读取的新闻RSS、iFinD试用、本机iOS工具链及现有服务器。此前“筹备全部完成”的判断不恢复；现在建议开工，是为了在明确资源和停止条件下验证完整用户路径。

产品目标不变：个人每天打开Web或iOS，主动看到重要变化，理解产业及A股公司影响，能核对依据和未知；独立个股分析辅助，不要求用户先做研究。

首包必须把真实来源、事件筛选、有依据的解释或停止推演、Web与iOS阅读串起来，并尽早打通真机签名。持续来源与原始补证、数据保存条件、网关计费/重试或iOS路径不成立，就先解决依赖，不扩展功能。单次调用、模拟器或静态页面成功都不能作为产品交付。

## 2. 核验改变了哪些判断

| 事项 | 本轮结果 | 剩余门槛与责任 |
| --- | --- | --- |
| 新闻发现 | 中新网RSS取得30条、美联储RSS取得15条，均有时间和链接；GDELT本次429，未盲重试 | CEO负责持续覆盖与使用边界；RSS开放不等于全文保存/改写许可，一次限流不等于永久不可用 |
| 金融与公司资料 | iFinD已登录；官方试用2,000次总量，页面26次已用；主营等有限查询成功 | 产品经理已列最低财务字段，工程首包核对一家公司；长期权益与保存条件由团队落实，不先购买 |
| 模型服务 | 现有Gemini凭据有效；一次真实生成成功，共5token；Cloudflare已存Google BYOK | 用户批准持续预算；架构师隔离网关策略。当前自动重试1次、成本限制关闭，不能照搬；完整网关链路和分析质量未验收 |
| iOS | Xcode、SDK、模拟器已安装；有效签名身份0，未发现连接真机 | 用户提供本机Apple登录/设备配合；团队核实版本兼容和分发规则，完成签名、认证及真机体验 |
| 运行 | SSH可用，主机当时可用内存约2.9GiB、磁盘余43G；Mac余667GiB | 架构师/Codex负责实际负载、加密机外备份和恢复；Mac离线时不能承诺24小时RPO |

本轮不要求另找Google、Cloudflare或iFinD账号，也不要求先购买服务器或数据套餐。Gemini探针只证明调用可用，不证明分析能力；来源单次成功不证明持续覆盖。

## 3. 团队已经作出的决定

- CEO对范围、投入、角色冲突和最终结果负责；产品经理负责行为及内容验收；架构师负责协议、可靠性、安全、成本；开发工程师负责实现。角色责任及此前分歧见[TEAM.md](TEAM.md)、[PRODUCT.md](PRODUCT.md)和[ARCHITECTURE.md](ARCHITECTURE.md)。
- ytrader持有产品规则、业务任务和数据；ycore持有采集与模型执行。接口和数据分别所有，不交叉读库、不重复调度。
- 模型沿用现有Gemini BYOK，经ycore统一执行；固定供应方，凭据缺失就失败，不自动切统一计费。隔离本项目策略，不直接修改可能被其他产品使用的共享网关。重试只保留受控的一层，未知结果不盲重发。
- 数据采用综合发现、原始补证、金融补充的组合。不能缩成“美联储+iFinD查询工具”；未确认使用边界的源不启用对应全文处理能力。
- Web+iOS均保留；首包尽早碰真实签名和认证问题。先用现有服务器和Mac备份方案，不新增采购；容量与恢复按实际证据放行。

本轮数据研究角色提供候选和最低财务字段；架构师补模型、网关、iOS与备份设计；Codex完成现场核验和裁决。研究中过度推断的许可、全市场覆盖和限流结论已剔除。开发工程师本轮未调用，未写应用代码。

## 4. 工作顺序与明确停止点

| 阶段 | 主责 | 放行条件 |
| --- | --- | --- |
| 开工授权与准备 | CEO/产品经理/架构师 | 用户批准首包及持续模型预算；团队锁定iOS依赖版本、冻结真实资料和预期；受限来源保持禁用 |
| 首个真实闭环 | 开发工程师，架构师和产品经理分别验收 | 真实来源持续可取、原始补证/处理边界成立、事件与公司证据连接正确；包含缺证停止；模型调用和预算可核对，Web/iOS完成核心路径 |
| 完整产品 | 开发工程师，产品经理负责行为 | 首页解释、产业与公司、独立分析、更新/更正及双端完整阅读；不扩大未经确认的数据范围 |
| 稳定交付 | 架构师/Codex | 按[DELIVERY.md](DELIVERY.md)完成相关故障、重启、费用、认证、备份恢复与回退；真实双端体验和用户接受 |

首包依赖不成立时停止扩展，不能靠fixture、减少iOS或把解释退化为新闻列表宣告完成。在首包结果出来后再细化工期，不虚构完整交付日期。

## 5. 集中需要用户的事项

1. **批准首包及持续模型预算**：建议1美元/日、10美元/月，按先到上限停止，包含调试及自动分析；不新增充值、不自动续费、不增加收费供应商。技术选型和网关隔离由团队处理。
2. **真机阶段提供Apple账号与设备配合**：在本机Xcode登录或确认已有账号，连接iPhone并完成必要系统确认。无需发送密码或密钥；先核实已有条件，不默认购买会员。

数据来源调查、模型配置、iOS兼容性和备份方案仍由团队负责。如必须联系供应商或购买权益，先给具体对象、内容、价格和用途，再集中请求授权。当前尚未获得应用开发或发布授权，停止点是交付本报告。
