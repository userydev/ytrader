# 新闻雷达：选题算法与产业入口（2026-10-20 草稿）

## 用户目标与授权
首页由算法选择新闻，不提供搜索或手动筛选。重点：全球重大事件/世界局势、主流媒体首页头条、权威媒体独家（可二手转述，必须保存出处身份）。右侧是随对象切换的多功能面板：阅读新闻、持续事件先前信息、各媒体报道、产业传导。新闻必须能连接多个产业，尤其原油、黄金、AI，进入产业核心视图。用户追加明确要求研究股票/投资项目的选题算法，不能仅增加RSS源。
授权直接交付可体验草稿，无中途确认。保留现有数据库、8000、58700、58710等预览。禁止采购、部署、外部通知、凭据复制/读取、绕过付费墙。新运行将使用独立数据目录和独立web-dist；宿主启动并基本检查，不增加全面测试框架。

## 实现层次
保留现有 NewsStore 的身份、稿件修订、同事件保守合并，不破坏历史。新增可解释的editorial投影：稿件版本→同一新闻事实/进展→持续议题。不同进展在时间线上分别保留；报道同一事实可并列媒体来源。不要把同主题的所有报道当成同一新闻。所有算法针对新入库新闻运行，不硬编码新闻标题/事件ID/置顶顺序。

1. 候选与质量门：来源可追溯；内容不是广告/购物推荐/APP下载/股票荐股榜单；源时间未知/未来保留标识，不以抓取时间冒充刚发生；原文语言保留。源日期超过7天不进入当前推荐，旧信息可进持续事件。首页观察可使用观察时间，但明确是首页观察，不能冒充发布日期。
2. 抽取可解释特征：命名主体/地理、事件动作/类型（政策、冲突、产能/供给、资本开支、订单、业绩、监管、利率/通胀等）、变化变量、直接/条件传导、独家声明、原始信息出处。中英规则要词边界和上下文，不能ai命中said、war命中award、Apple水果当公司。新闻事实和规则推断分开。
3. 多路召回：a全球重大进展/宏观与产业催化；b真正的主流媒体首页观察或明确媒体首页精选；c明确独家/权威原创声明。不能用RSS顺序假装头版。独家缺席就为空，不为了填区块伪造。没有证据，不自动声称全球热榜第一。
4. 排序：基本面/供需/政策/风险变量的具体变化、新信息、独立出处、首页版位、可信独家、时效。多来源只是关注范围证据，不等于事实已证实。转载同一通讯社只算一条出处。纯价格回顾、消费促销、无新增事实评论降权。重大单源官方变化/独家不能因少来源消失。权重是v1启发式，不是校准市场影响概率；记录各项理由和抑制原因，允许后续重放调整。
5. 重排：限制同一个持续议题重复占位；不要高频IT源淹没世界新闻；三路合并排序并标注可读入选理由；不保证每路固定凑数。相同事实转载不刷新事件新鲜度；真实更正/新数字/新动作/状态变化可形成新进展。不靠"战争"一词声称重大新增。
6. 持续议题：稳定可追溯的story ID，明确关联依据；中英别名+相关主体/动作/时间约束。可提供俄乌局势、中东与航运/能源、AI资本开支与供给、贸易管制、央行利率等有限可解释议题规则，但不能把所有AI新闻都并为同一事件。同议题是背景联系，不宣称独立验证。保存最早观察、最近事实时间、阶段、进展列表；无历史要如实显示起始收录日期。
7. 产业多对多：对每个关联输出 industry_id/name、variable、mechanism、condition、evidence (article_id/原文触发片段)、node_ids、relation=direct|conditional。方向按各产业/环节拆，不能统一利好。原油供给/航运→供给与运输成本；黄金→避险/实际利率/美元/需求；AI→资本开支/芯片管制/服务器与电力。地缘事件仅在经济传导有依据时关联原油/黄金，不能任意国家新闻连三产业。没依据宁可不映射。行业名不是最终交付，要能点入同一新闻上下文的产业骨架。

## UI方向和路径
继承58700/现新闻页暖白+蓝色操作色与标题→横线→内容。Read/Operate桌面场景，信息密度清楚，避免大卡片堆砌、装饰/系统统计/算法数值占首页。既有8000不影响。
新首页主栏推荐新闻流（有主次，重点事件领先）；每条有标题、关键事实摘要（来源摘要，不伪造中文翻译）、来源/时间、1-2条入选理由、可点产业关联。保留原英文标题，若无真实中文译文不能生成泛泛“出现新进展”替换具体标题。列表不是全量RSS，也不是搜索页面。必要的三路身份是新闻属性，不是筛选控件。顶部只有新闻/产业和设置入口；新闻源健康放来源设置。
右侧常驻约36%：默认选中第一条，显示本次变化、来源内容、持续事件摘要/先前进展、多媒体报道、产业传导；选择报道后查看该稿，选择议题后查看时间线，选择产业后查看变量→机制→条件+进入产业图。可以小tabs切换上下文视角（不是新闻筛选）。每处事实/推断清楚但不铺满免责声明。保留真正原文链接与版本，不把二手拿到摘要当权威一手全文。未获取原文时显示原始出处被转述且链接可用与否。
新闻列表选择状态可用?story/event保留，刷新/后退有恢复；旧/events/:id详情仍能打开。首次无数据/采集中/源失败时需可恢复，不拿空列表当正常已精选。更新不自动夺取阅读位置。

## 接口和联动
新增 /api/v1/news/editorial（envelope），返回推荐列表、选题理由/证据、可选择的story/报道/产业上下文及生成时间；可另设detail/diagnostics，具体结构自行清晰定义并前后端一致。远端模式不悄悄回落本地（未支持报501）。统计/权重/排除原因可在设置或文档，不在首页。
宿主另建产业预览http://127.0.0.1:58721/（原58700保持），通过 VITE_INDUSTRY_PREVIEW_URL 设置。新闻跳转约定 ?industry=crude-oil|gold|ai-compute|grid|innovative-drugs&news=<event_id>&return=<新闻首页URL>。产业页将向58720的editorial API请求该news上下文；必须提供按event ID访问新闻投影（GET /api/v1/news/editorial/events/{id}）；payload明确event,title,summary,articles,industry_links。宿主安排独立产业接入实现。这个接口和industry_links node_ids必须稳定：原油 extraction/crude/refining/fuels/logistics/feedstock/chemicals/transport；AI请读现有同名数据映射后使用实际节点；gold由新黄金页面提供 mining/refining/bullion/investment/jewellery/technology/recycling。无根据不塞company ids。
