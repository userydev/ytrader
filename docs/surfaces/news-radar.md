# 新闻雷达页面契约

记录日期：2026-10-20。状态：桌面可体验稿，待用户体验认可。当前入口为 [推荐新闻首页](http://127.0.0.1:58720/events)，产业桥接为 [独立产业画布](http://127.0.0.1:58721/)。

本契约取代 2026-10-19 的默认 RSS 搜索/筛选首页方向。用户已否定 58710 的默认体验；该预览保留仅为保护既有工作，不作为当前首页设计依据。最新依据为 [EDITORIAL-BRIEF.md](../EDITORIAL-BRIEF.md) 与 [NEWS-SELECTION.md](../NEWS-SELECTION.md)。

## 目标与方向

首页由算法选择值得关注的新闻。用户先读新增事实，再核对出处、先前进展和产业传导。主模式为 Read；右栏对象切换与来源设置采用 Operate。新闻流覆盖全球重大进展、投资催化、媒体首页线索和有明确声明的独家；不以全量 RSS 条目代替选题。

首页不提供搜索、手动来源/时间/内容筛选、最新/热点切换、来源健康或统计仪表盘。顶部保留新闻、产业、设置及更新新闻。三路召回是推荐依据，不是筛选控件。空缺独家不补假条目，无数据不补示例新闻。

延续现有产业工作台的暖白、蓝色交互、系统字体和细分隔线。本轮没有批准新视觉世界。产业桥接新增黄金并携带新闻上下文；原 58700 产业稿及其他已有运行保护。手机、行情、公司策略和交易功能不在本页契约内。

## 入口与对象切换

| 入口 | 行为与内容 | 上下文 |
| --- | --- | --- |
| `58720/events` | 默认算法推荐；首条重点新闻领先，右栏默认打开首条 | 选中新闻与右栏标题对应；再次选择才切换对象 |
| 右栏“阅读” | 来源正文/摘要/标题、发布媒体原文、来源说明与版本、入选理由 | 优先显示当前进展的主稿，可选其他媒体稿或修订 |
| 右栏“持续事件” | 持续议题依据、最早收录、最近事实、已收录进展时间线 | 点击历史进展进入对应新闻；不生成不存在的历史 |
| 右栏“各媒体报道” | 发布媒体、去重出处线索、转述身份、独家声明、稿件版本 | 选择稿件切回阅读视角 |
| 右栏“产业传导” | 变化变量、机制、条件、原文触发证据、相关环节 | 同一新闻可关联多个产业，逐产业切换 |
| `58721/?industry=…&news=…&return=…` | 携新闻进入产业图，定位关联节点，切换关联产业，返回新闻 | 保留原新闻标题及返回地址；不替换原 58700 稿 |
| `58720/sources` | 顶部“设置”所指的来源管理；推荐规则与审计按需展开 | 健康、质量、启停、RSS 与算法诊断留在设置 |
| `58720/events/:id` | 兼容旧版完整详情与研究入口 | 次级阅读路径，不恢复旧版默认首页 |

新闻选择使用 `event`（兼容 `news`）、`story`、`progress`、`article`、`view`、`industry` 查询状态。点击选择通过路由历史更新，默认首条以 replace 写入；旧 `q/source/period/content_level/sort/tag/limit` 不参与推荐，新的选择动作会移除它们。右栏切换新闻、稿件或视角时回到该内容顶部；不能将此写成所有滚动位置都已恢复。

更新新闻只触发采集和进度提示，不自动替换正在阅读的结果。完成后由用户点击“载入更新”。空库、采集中、来源不可用、暂无合格推荐和接口错误分别显示；空态可进入来源设置恢复。正常首页不铺开逐源健康信息。

## 布局与阅读层级

**标题 → 横线 → 内容。** 页题、“值得关注”“阅读与传导”及右栏内容模块的标题位于下方分隔线上方。新闻项连续排列，不堆独立大卡片；第一条用字号建立主次，选中底色和细蓝标记关联左右内容。

当前局部实现记录如下，不提升为全局 token：

- 页面最大宽 1560px；主栏与右栏约为 1.78:1，栏距 36px，右栏最低宽 345px。宽屏与紧凑屏有局部调整。
- 右栏常驻并在滚动时保持可见；内容区独立纵向滚动，视角 tabs 只改变当前新闻上下文。
- 页题 30px；头条 26px，普通新闻标题 19px；列表摘要 13px、行高 1.75，普通条目最多三行，头条最多四行。
- 右栏标题 20px；来源内容 13px、行高 1.95，按纯文本段落呈现。来源、时间、入选理由与版本说明使用较弱层级；详细证据可展开。
- 入选理由在列表最多展示两条，更多依据进入右栏。无真实译文时保留原英文标题与摘要，不用泛化中文替换具体事实。
- 焦点轮廓、选中语义、加载和错误反馈保留。源码有窄屏降级，手机未设计或验收；桌面证据宽度为 1280/1405px。

## 选题、时间与出处边界

选题策略依次进行质量门、多路召回、排序、同议题及来源多样性重排，并保留理由。具体变量变化、新信息和可追溯出处优先；稿件量、关键词或市场涨跌不单独构成重要性证明。权重是启发式，不是市场影响概率。排序和归并的语义准确率未验收。

时间显示沿用北京时间。来源发布日期、首次观察、首页观察、采集、最早收录、最近事实分别表达。未知/无效/未来日期保留说明，不以抓取时刻伪造刚发生。媒体首页观察记录版次、位置与观察时间；首页精选 RSS 不等于抓到实际头版版位。持续议题从实际收录起点开始，不声称完整历史。

稿件版本、新闻进展、持续议题是三层对象：修订保留旧版本，同一事实的多媒体报道保留各稿，同一议题的新进展形成时间线。共享国家名或 AI 主题不自动等于同一事实。界面中的阶段线索来自报道标题，不能写成独立确认。

“来源正文”“媒体摘要”“来源标题”分别展示；正文由订阅流提供时说明未另抓文章页，摘要不能冒充全文。发布媒体原文与被引原始出处分别命名；转述稿不能自动获得一手身份。独家自述和二手独家声明保留证据，未获取或未核实可达性的原始链接如实说明。多发布媒体不等于多独立出处，更不等于事实已证实。

来源说明、版本、语言规则识别和时间质量提示可展开核对。推荐规则、权重、排除记录属于设置诊断，不占首页主体。来源管理保持保存不等于采集成功、暂停不删除历史、失败保留旧数据的边界。

## 多产业桥接与黄金画布

每条产业关联分别给出变量、机制、条件、触发片段和节点；可区分直接变量关联与条件传导。没有依据就不关联，不把地缘词统一映射到原油、黄金、AI，也不将机制框架参考当作本条新闻证据。

桥接页保留新闻标题、关联产业切换和返回新闻入口。黄金画布展示采矿、精炼、标准金与流通、回收、投资与储备、首饰需求、技术与工业需求的供需关系。节点显示短机制与短条件，完整解释在右栏；黄金投资属于需求用途，回收形成回路。关联不表示金价必涨或黄金公司必受益。

本轮截图显示黄金七节点名称及供需分支可在首屏辨认；下排说明和长正文仍需纵向阅读。产业页保留的公司搜索属于产业工作区，不等于新闻首页恢复手动筛选。
