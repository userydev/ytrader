# 产业交互结构重做 · 可体验草稿

用户否定上一版长文阅读：UI混乱、数据堆砌，无法理解产业。PPT只是清楚表达的比喻，不是幻灯片、分页故事或演示文稿。目标仍是讲清产业怎样运转、关系和公司位置。当前未获体验认可，先交付可操作版本，只检查运行和既有工作保护，测试后置。

## 决策

把主界面改为可探索的产业结构。入口只有产业名称、一句机制、完整主干图和当前焦点。图的空间关系承担解释；正文只解释选中环节。保留当前应用颜色、中文系统字体、三模块导航，无营销式视觉改版。

- 产业名为详情唯一主标题，不重复通用“产业”标题。目录返回、版本选择、继续提问属于紧凑工具栏。
- 首屏直接呈现结构。AI算力主干为GPU计算部件→AI服务器→AI集群→训练与推理；网络/存储/软件作为协作配套，供电/散热作为运行条件。不能把全部节点排成加工流水线。
- AI算力一句机制：“把计算部件组织成协同工作的系统，完成模型训练与推理。”节点用短名称与短功能句，完整名称留详情。例：GPU/执行计算；服务器/承载计算部件；集群/组织多机协作；训练与推理/运行模型任务；网络/交换数据；存储/提供数据；软件/分配任务；供电/提供电力；散热/带走热量。此为现有资料的编辑表达。
- 原油呈现开采→原油→炼制，炼制分流至燃料/化工原料再到用途，储运为支撑。创新药呈现研发阶段及服务跨阶段支撑，流程先后不表示必然获批或成功。不能套同一固定三栏序列。
- 点击节点/连接在固定详情区展示：它做什么、与哪些环节相连、谁在参与。连接可继续选择邻接节点。公司链接使用既有已核对symbol与返回上下文，不能编公司或证券代码。
- 公司位置作为图的可选视角，选择公司高亮参与节点，点节点查看具体角色；不用另起重复公司长列表。基础视角默认环节。
- 公共参考与已保存AI补充用版本选择切换同一个工作区。AI补充不在主图下再堆一整篇。保留模型、日期、未核查、陈旧提示。公共数据不改写、不混成已核实事实。
- 继续提问在邻近图的工具入口打开同一侧栏/下方区域；保留问题建议、提交、后台进度与历史。只显式提交触发模型。不需要本轮新模型调用。
- 依据、完整解释、区别、覆盖缺口按需展开；所有原有内容可访问，但不预先占用主界面。不要把段落换成等尺寸卡片，不能仅折叠旧报告。
- 对任意AI新产业/补充都用同一图与焦点交互。公共三例可用语义布局配置；动态结构用有向层次布局/分支，保留全部节点与关系，循环/孤立节点也不丢失。布局是呈现，不制造事实。
- 约700px实际应用面板也必须可读，文字不能随SVG缩到10px。窄屏将详情置图下方；图需要响应式布局/局部可滚动，不让整个页面横向溢出。
