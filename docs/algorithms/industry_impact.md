# industry_impact 1.0.0

与宽关联独立。输入：当前新闻稿件、用户选择的实际产业图、资料版本。原五产业条件规则仍可用；开放产业使用相同模型适配在按需后台 job 中补充。

输出最多6条条件影响，每条1–8个实际节点ID，影响变量、待核实机制、成立条件/反证、原稿ID与逐字新闻摘录。拒绝未知节点或改写的证据；不输出/新增新闻因果边，不能把结构图边直接当因果。source_record / AI 图保持原来源身份；推断统一未核实。

绑定新闻内容哈希、industry ID、图版本及算法版本；GET 只读缓存，POST 创建去重任务，已有版本复用。缺失/失败不解释为现实中无影响。客户端在所选产业中高亮实际定位节点，列出这些节点的原资料参与公司，不据此宣称公司财务或股价已受影响。
