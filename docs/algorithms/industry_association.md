# industry_association 1.0.0

输入：不可变新闻稿件、动态资料目录（含实际产品别名）、目录版本。输出：多对多主题关联，允许目录外名称，以稳定 open-* ID 进入研究。关联没有因果边、不要求 node_ids，不代表影响已发生。

纯算法快速匹配保留原文触发证据；安全事件地域关联有安全/冲突条件，避免普通地域体育/娱乐新闻泛化。IO 层在明确阅读新闻/手动更新时 POST 排队，经现有模型适配补充目录外名称；不在同步 GET 或 feed 轮询中调用模型。响应最多12项，名称/文章ID/逐字引文/简短理由均校验。结果绑定新闻内容及目录版本；KV 缓存、Jobs active_key 去重，失败保留快速层。

目录不是五行业白名单。CKG 行业目录可作快速层，不将全部产品喂给模型；产品匹配首先使用已有包内结构与别名。模型宽关联统一标为 ai_association。
