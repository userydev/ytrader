# 新闻雷达界面：可体验版本

用户要求首页排版、详情阅读、新闻源、组合筛选与去重解释。阅读优先，沿用已认可产业稿的暖白/蓝色/标题→横线→内容，不重做产业/个股。不需要概念选票或再次询问。新UI先可运行草稿，只检查启动和关键入口；无全面回归。使用docs/NEWS-RADAR-BRIEF.md接口，其中唯一笔误纠正：同步为 POST /sync {kind:'news'}，不是POST /jobs。

## 参考与取舍
宿主已真实浏览Horizon(Thysrael上游及中文日报)和NewsNow：采用Horizon标题/来源/时间/段落的清楚层次、NewsNow每源状态与更新时间；不采用巨幅渐变页头、来源卡片墙、首页自动AI评分及强制AI摘要。Miniflux/Feedbin的阅读任务流与来源管理为方法参考。其余源码研究正在进行，后续必要结论由Codex反馈。所有实现原创，不复制第三方代码。

## 设计契约
Read模式（首页/详情）+Operate（筛选/来源）。桌面优先，1280/1405宽无横向溢出。背景#FAF9F5、纸面#FFFEFA、正文#243549、次要#617080、蓝#315E94、浅蓝#E7EFF8、线#D9DEE3。系统中文无衬线；控制14px、新闻标题19-20px/1.5、列表摘要14px/1.7、详情正文17px/1.9、详情标题28px/1.45，段落宽约760px。各区标题上、分隔线下、内容再下，不要上边框贴标题，不用嵌套卡片、厚左色条、装饰图标、渐变或大统计牌。

首页首屏：紧凑顶栏ytrader/新闻/产业/新闻源；页面标题新闻雷达，旁边紧凑来源状态与抓取时间，右边更新新闻。直接出现新闻列表，不默认自动打开第一篇。工具行搜索+最新/热点切换；下一行来源、时间（全部/24h/7d）、内容（全部/源提供正文/摘要/仅标题）select，活动筛选和清空。主栏约75%，右栏260-290px，模块主题分布（真实overview topics可点tag筛选）、新闻来源（名字/启停/最近检查/失败提示，管理入口）、收录说明（去重和覆盖简短解释）。头部统计只平铺一行小字，不能抢新闻。列表按源日期分组可选，每条标题+最多两行摘要+来源/北京时间/原始稿件数或多来源；不堆tag，未知日期明确。热点页清楚说明是已接入源内规则排序，不是全网热搜或阅读量。

筛选API和URL状态完全同步：q,source,period,content_level,sort,tag,limit。切换筛选重置limit；分页加载最多500并准确停止。来源筛选传name不是id。query交集。返回列表保留筛选与滚动位置（至少当前已载limit）。不轮询导致阅读跳动，后台完成更新后可显式重新载入。

详情：独立页 /events/:id 保留查询；返回新闻列表；宽舒适主文章，右边来源与修订记录。使用primary_article_id，缺失时最新文章；选来源/版本后标题/时间/正文同步更新。正文纯文本按段落，不dangerouslySetInnerHTML；标题与摘要重复时不重复。摘要标来源摘要/非全文，可读原文始终可找。未知/未来时间质量提示用自然中文。来源及修订区别，不把两版本写成两独立媒体。最小研究入口可保留原有事件研究折叠，但不主动调用AI。保留AnalysisView导出被其他页使用。相关产业入口不成为空主体/抢阅读区。

来源管理：/sources独立页，显示覆盖说明、内容级别、最近检查/成功/源最新发布、错误、received/added/duplicates/rejected/revisions（本次/累计口径明确）。启用/暂停能PATCH，不删除数据；未接入paid来源不可启用。新增RSS名称+URL原表单POST /sources；更新新闻POST /sync并用现有JobProgress轮询直至结束，更新来源与列表。显示暂未采集而非成功；失败旧内容保留。操作错误有可见反馈。

Shell：新闻/events及/sources使用紧凑横向导航，新闻上不要旧全高侧栏；其他已有route布局保持。产业/公司导航可按构建环境VITE_INDUSTRY_PREVIEW_URL链接到已认可产业稿，未配置时仍内部/chain，避免写死localhost。可新增src/env.d.ts导入vite/client类型。新运行由Codex用独立dist和数据目录启动，不改现有8000页面。必要API/type可兼容扩展，不能让旧页类型全坏。

使用lucide已有库且图标仅动作有用才加；控件/焦点/加载/错误/无结果完整。前端只能请求后端API，不能直连第三方或读取凭据。所有状态来自真数据，不构造假热点或假成功。
