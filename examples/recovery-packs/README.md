# 原创产业关系包

2026-10-18核读企业公开官网与报告后编写。MIT许可仅适用于本项目原创图结构和事实摘要；原网页与报告版权归原权利人。未复制第三方产业数据库。

七个主题是有来源的起始覆盖，不代表完整A股供应链。证券公司节点与证券主表共用ID。`classification`只表示业务/产品归属；`upstream`只表示来源支持的工艺或组件关系；没有证据时不写入公司间供货关系。报告证据保留历史日期，不把核读日期当报告日期。

运行时目录在 `backend/data/packs`，可从产业页安装。此目录留作可审阅的源样例。页面来源、原始证据和日期均在JSON内；企业宣传性表述不作为收益结论。
