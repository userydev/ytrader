# ytrader

**个人 A 股信息与研究工作台**：阅读新闻，进入相关产业链，查看环节、板块与上市公司，并按需使用传导分析及多种个股研究策略。用户自行判断交易，不提供买卖指令。

**最小使用路径：真实新闻 → 相关产业链入口。** 产业链/公司信息可独立浏览；传导解释和个股深度分析是可选入口，不是打开新闻时必须自动运行的流程。

## 两仓分工

- **Y-Core**（单独仓库）：Radar（获取/规范化/更新有出处的新闻及材料）、AI（受控模型执行、结果与费用/失败状态）。不固化金融业务、产业链关联规则或个股策略。
- **ytrader**：新闻展示、产业链/环节目录、新闻与产业链的关联、板块/公司业务资料、可选传导解释与多策略个股分析。业务规则和产品体验以本仓库为准。

## 文档

- [PRODUCT.md](docs/PRODUCT.md)：完整功能模块、职责所有权、三类必须区分的关联关系、用户可选自动化原则。
- [PLAN.md](docs/PLAN.md)：跨仓消费合同、P0–P5 按阶段交付、可验收用户路径与 Codex 协作。

两个仓库独立开发和测试；从 ytrader 的实际消费需求制定最小接口，最终由 ytrader 页面验收。不继承被清空的旧系统实现或计划。

## 分支

- `dev`：日常开发（默认）。
- `main`：稳定发布，从 `dev` 集成。
