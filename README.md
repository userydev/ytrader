# ytrader

**个人 A 股信息与研究工作台。**

通过「**新闻 → 产业链 → 事件传导 → 行业板块 / 个股 → 多策略分析**」组织公开信息，帮助用户理解事件、产业和上市公司的关系。产品提供信息和不同研究视角，是否交易由用户自行判断。

当前为完全从零开发；不继承旧功能或旧进度。**首版不做交易建议、持仓管理、交易计划、回测或自动下单。**

## 文档

- [PRODUCT.md](docs/PRODUCT.md)：产品定义、新闻/产业链/板块/个股路径、多策略分析与两仓边界。
- [PLAN.md](docs/PLAN.md)：按可点击样板 → 新闻供给 → 传导展示 → 个股多策略 → 稳定性推进。

**ytrader 是唯一产品需求源。** Y-Core 在独立仓库开发，根据 ytrader 的具体材料、数据与 AI 消费需求提供技术支持，不单独规划产品方向。

## 分支

- `dev`：开发主分支（默认）。
- `main`：稳定版本，由 `dev` 集成。
