# ytrader

**个人交易决策台**：从真实事件与产业链状态变化出发，分析影响环节与相关上市公司，形成可追溯、可验证的个人交易假设和决策计划。

本仓库是产品与需求源；技术服务 **Y-Core** 在独立仓库开发，按 ytrader 的真实消费者需求确定范围。当前为全新项目，不继承任何旧开发进度或功能。

## 文档入口

- [产品定义（V0，待确认）](docs/PRODUCT.md)：目标、核心用户闭环、产业链状态、个股与交易计划、Y-Core 职责边界。
- [开发计划（P0，待确认）](docs/PLAN.md)：验证样板、分阶段交付、验收和跨仓协作。

## 分支

- `dev`：主要开发分支，也是默认分支。
- `main`：稳定发布分支，稳定版本从 `dev` 集成。

**当前阶段：P0**，先确认交易周期及首个真实用户流程，不直接开始大规模平台实现。
