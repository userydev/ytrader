# ytrader 中文研究工作台

React / TypeScript / Vite，真实接入 `docs/IMPLEMENTATION-BRIEF.md` 中的 API v1。没有 mock、演示行情或自动注入的产业数据。

## 启动

需要 Node.js 22+。先按后端交付说明启动 API，监听 `127.0.0.1:8000`，再执行：

```sh
cd frontend
npm install
npm run dev
```

打开 Vite 输出的本地地址（默认 `http://127.0.0.1:5173`）。开发与 preview 都将 `/api/v1` 代理到 `http://127.0.0.1:8000`。

```sh
npm run build       # TypeScript 检查 + Vite production build
npm run preview     # 本地查看 dist，默认端口 4173
```

本 worker 按约束未执行安装、构建、测试或浏览器操作；最终候选的安装、锁文件、类型构建、安全审计和浏览器验收由宿主执行。React Router 已按宿主要求设置为 `^7.18.4`。

## 首次使用

1. 在“设置”分别选择数据模式与 AI 模式；本地数据服务无需依赖 ycore。
2. 检查新闻来源，必要时添加自定义 RSS。iFinD 仅显示停用的能力声明。
3. 在“任务”同步证券主表与新闻，查看进度及每个来源的失败原因。
4. 同步证券可生成来自真实来源的行业分类。在“产业链”先查看行业分层目录，再深入行业或公司局部关系。分类不是供应事实；其他产业关系可导入有来源、许可、时间和完整证据引用的 JSON。
5. 在“事件”阅读原始证据、更新和纠错。未配置模型时仍可研究来源；模型分析需单独配置，服务返回 409 时显示真实错误，不生成假分析。
6. “证券”显示沪深北覆盖、公司详情、关注列表、实际行情、事件及产业路径。覆盖不足不推断退市；行情不可用不填充示例价格。

## 产业图的范围与证据

- 默认展示行业 → 产品 → 环节目录，不绘制全市场公司大图。
- 从行业、节点检索或公司详情进入局部图。使用当前 API 已返回拓扑做两跳广度优先选择：最多 12 个相连节点、24 条边，保留起点、终点和连通骨架，不按全市场 ID 截取前几十个孤立节点。
- API 默认返回上限及 `gaps` 如实展示。目录计数仅属于当前返回范围，不宣称全市场完整；搜索可缩小范围。
- 点击图中节点或关系（或使用 Tab / Enter / 空格）进入证据检查区，可打开证据详情与原始来源、转到公司研究、以节点继续深入。
- `classification` 统一标为“业务分类（非供货）”，可表示公司与行业、主营产品或环节的挂接，不能一律称为所属行业，具体含义由路径 condition 说明。细实线配明确的披露 / 业务分类 / 上游标签；推断关系为虚线。关系表作为完整文字替代，保留所选节点在已返回数据中的全部直接关系，不受图节点数量限制。
- JSON 导入提供文件选择与文本粘贴。前端检查基本 JSON 结构；许可合法性、时间、引用完整性、事实证据和事务一致性由 `/chain/import` 后端权威校验。

## API 与状态处理

`src/api.ts` 统一使用同源 `/api/v1`，读取 `{data,meta}` 与 `{detail}` 错误；页面呈现来源、数据时间、完整性与 warnings。发布时间未知显示未知，不拿抓取时间替代。URL 只允许无用户名密码的 HTTP(S)；内容以纯文本呈现，不执行来源 HTML。

- 事件：列表搜索、逐步扩大 limit、详情、文章证据、六类分析、分析任务、陈旧分析提示、产业路径。
- 证券：搜索、交易所筛选、覆盖、详情、行情、关注列表与公司事件 / 路径。仅关注筛选同时保留全部已关注证券入口，不把初始搜索窗口误当完整关注列表。
- 产业：行业目录、局部图、节点检索、关系证据、路径、JSON 导入。
- 任务：同步新闻 / 证券 / 全部，状态过滤、前台轮询。API 没有取消或分析重试接口，不虚构按钮。后端已确认 `Job.progress` 范围为 0..100，界面直接以百分比显示，不额外乘以 100。
- 设置：数据与 AI 独立选择；模型、ycore、自动分析、同步间隔；`sync_interval_minutes` 设为 0 关闭定时同步，不影响任务页手动同步；RSS 添加与开关、来源状态及错误。

桌面是导航 / 目录 / 宽详情；窄屏仅显示目录或当前详情，保留目录返回与跨公司 / 事件的研究返回路径。证据使用原生模态 dialog，支持 Escape、焦点约束和关闭后返回触发控件。请求变化时中止旧读取，任务与详情定期刷新，错误可重试；不将空数据当作已完成研究。

## 密钥与部署

- 密钥只允许密码输入，不读取或回显已存值。不使用 localStorage、sessionStorage、前端环境变量、日志或 URL 保存模型 / ycore 密钥。空白输入不覆盖已有密钥；显式勾选清除并保存才删除。
- 模型调用由后端负责；前端不直接请求模型、不转发 ycore token 到自有模型。托管 AI 的 Cloudflare AI Gateway routing 需由远程服务实际部署与声明；本页面不宣称 ycore 已上线。
- 生产部署提供 `dist/` 静态资源，并将同源 `/api/v1` 反向代理到后端。使用 BrowserRouter，静态服务需要将非 API、非静态文件请求回退到 `index.html`，支持详情页刷新。`vite preview` 仅用于预览，不替代生产 Web 服务。
- 生产环境使用 HTTPS，不将后端 API 裸露到不可信网络；鉴权 / 权益不属于本地首版。
- 更新前停止写入并按后端文档备份 SQLite 与服务端配置；备份含服务端凭据应限制权限。前端仅为可重新构建的静态文件，不另存研究数据或密钥。
- 开源许可遵循宿主仓库独立 LICENSE；本前端没有捆绑第三方产业知识数据。

## 建议宿主验收

执行安装 / 锁定、`npm run build` 与安全审计，然后浏览器验证：空库同步 → 任务 → 事件原文 → 未配置模型 409 → 配置 → 分析任务 / 六类证据；三所覆盖、缺失行情、关注增删；500 节点响应下行业目录与有限相连局部图、图中节点 / 关系证据；有效及拒绝的 JSON 导入；四种数据 / AI 模式组合、空密钥保留与显式清除；RSS 添加与停用；桌面及 390px 手机的键盘、模态焦点和研究返回路径。
